# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
in short: be respectful, assume good faith, and keep disagreements about
code and ideas rather than people.

Unacceptable behavior includes harassment, personal attacks, and other
conduct that would reasonably make someone feel unwelcome contributing here.

To report a concern, please contact **hey.tejjas@gmail.com**. Reports will be
handled as discreetly as possible.
